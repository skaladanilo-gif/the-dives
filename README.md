# The Dives

Site de estudo de **Redação Publicitária** para estudantes da UVV (Universidade Vila Velha).

- Resumo de todos os slides da disciplina
- Quiz de alternativas com correção e explicação
- Flashcards 3D
- Treinos: Monte a peça e Laboratório OOH
- Como cai na prova: padrão das atividades do professor

É uma página única (`index.html`), sem dependências. Para publicar, basta ativar o GitHub Pages na branch `main`.
